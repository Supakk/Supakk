## Hi there 👋

I'm a junior developer who works across ERP systems and frontend web development. I'm still early in my career and learning a lot from real projects and from the people I work with.

- 🏭 At work, I customize **Infor CloudSuite Industrial (CSI)** on the Mongoose framework, mostly with T-SQL stored procedures, VB.NET form scripts, and custom IDOs.
- 💻 I also build the frontend for internal web apps that connect to ERP and back-office systems, using React, TypeScript, and Next.js.
- 🌱 Before this, I did a front-end internship at **I know plus**, where I added video support to existing websites and made them responsive on different screen sizes.
- 🤝 I'm always happy to get feedback on my code. If you see something I could do better, please let me know.

**Side projects and practice**
- [**Guess-guess**](https://github.com/Supakk/Guess-guess): a studio website built with Next.js, Tailwind CSS, GSAP, and MDX. [Live site](https://guess-guess.vercel.app)
